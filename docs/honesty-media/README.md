# Honesty media

Soft Dist launch criterion: every host must complete a **geo-proven**
property scan before a home can be bookable. Reconstruction may stitch,
stabilize, compress, and clean up — it must not beautify or invent rooms.

Bookings stay off until Nick sets `ALLOW_GUEST_BOOKINGS=1` after this
phase ships and is required. This directory is the plan, not the
implementation.
